# Пульт контента

Страница: https://jetmetrics-io.github.io/content-pult/ — вход по паролю.

Здесь только код страницы. Идеи, посты и тезисы — в закрытом репо `jetmetrics-io/content-system`;
страница читает и правит их через API GitHub ключом из `auth.json`. Ключ зашифрован паролем
(PBKDF2-SHA256, 600 000 итераций → AES-256-GCM) и расшифровывается только в браузере.

Исходники и скрипты — `content-system/_pult/` (`deploy_web.sh` выкладывает сюда, `set_password.sh` меняет ключ и пароль).
Руками здесь не править: следующая выкладка перезапишет.
